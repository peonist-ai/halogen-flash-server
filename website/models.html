The roster

Models

A request picks a model by its model. Every request that names no NPU model goes to the Flash model. Name the NPU models you want in HALOGEN_NPU_MODELS.

On the GPU

Every request that names no NPU model goes here.

Larger sizes of the first three NPU kinds are named the same way, and your own fine-tune of a decision, embedding, reranking or moderation model runs on the NPU too. See NPU host details. The Flash model's id can be changed with HALOGEN_MODEL_ID; /v1/models lists what is loaded.
